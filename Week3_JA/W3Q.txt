Q2. What are dropdowns and how do we handle it in playwright?

1. standard dropdown/native dropdown
2. custom dropdown


Ex:<select id="country">
  <option value="IN">India</option>
  <option value="US">United States</option>
  <option value="UK">United Kingdom</option>
</select>

standard dropdown/native dropdown:

3 ways

select by value - p1
select by index-p3
select by label-p2

await page.selectOption('#country',{value:"IN"})
await page.selectOption('#country',{index:2})
await page.selectOption('#country',{label:"United States"})


Q3. How do you handle a dropdown that doesn't use the standard <select> tag but is built with a <div> or <ul> 
(custom dropdown)?

Handling Custom Dropdowns (Built with <div> or <ul>)

Example:
<div class="dropdown">
  <div class="option">India</div>
  <div class="option">USA</div>
  <div class="option">UK</div>
</div>

custom dropdown:

//first click to select the dropdown
await page.locator(".dropdown").click()

//select the option
await page.locator('.option',{hasTex:'USA'}).click()
