Q7. How to automate file upload using playwright?

1. with input[type="file"]-> directly inject the file to upload using setInputFiles('path')

2. without input[type="file"]-> create the event listener and promise is also created

let fileupload=page.waitForEvent('filechooser') //listerner and promise is created
await page.locator('upload').click()  //trigger the click action
let fup=await fileupload //resolve the promise and have the ref for fileupload
await fup.setFiles('path')
