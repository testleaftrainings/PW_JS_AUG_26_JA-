Q4.You are designing test data for an automation framework. An application has Admin and Tester 
users. Sometimes a test accepts either an Admin or a Tester, while another test requires a user to
 have both Admin and Tester details. How would you model these two scenarios in TypeScript? Explain 
 the difference between union and intersection and when you would prefer each.

type alias

1. type union(|)---> either this or that(a|b|c)
2. type intersection(&)----> 2 types will be combined into single type and that will be used to 
access both type

type Admin={
    username:string
    accesslevel:number
}

type Tester={
  
  id:number
  testTool:string
}


//use type union to restrict the access

type singleAccess=Admin | Tester

//use type intersection for both the access

type dualAccess=Admin & Tester
